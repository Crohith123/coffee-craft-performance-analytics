# ☕ Coffee Craft Performance Analytics

## Power BI Coffee Sales Dashboard

An interactive Power BI dashboard developed to analyze coffee sales performance across time, stores, item categories, and individual items.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- Time Intelligence
- Interactive Slicers

## 📊 Key KPIs

- Gross Sales
- Net Sales
- Sales YOY
- Sales Last Month
- Total Orders
- Quantity Sold

## 🎛️ Interactive Filters

- Year
- Quarter
- Month
- Item Category
- Store Code

## 📈 Dashboard Visuals

- Gross Sales by Year Month
- Total Sales and Net Sales by Year Month
- Total Sales by Item Category
- Total Sales by Item Name
- Discount Amount by Year Month
- KPI Cards

Interactive filtering and cross-highlighting allow users to explore sales performance dynamically by time period, store, category, and item.

## 🎯 Project Objective

The objective of this project is to transform coffee sales data into an interactive business intelligence dashboard that supports sales monitoring, trend analysis, category comparison, item-level analysis, and store-level filtering.
